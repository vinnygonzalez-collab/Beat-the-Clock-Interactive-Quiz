# Beat the Clock: Interactive Quiz

A timed quiz game built with JavaScript. Test your knowledge, race the clock, and try to achieve the highest score possible.

Live Demo: https://beattheclockquiz.netlify.app/

## Features
- Countdown timer for every round
- Multiple-choice quiz questions
- Score tracking as you play
- Interactive JavaScript-driven gameplay
- Clean, responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Play
1. Open the live demo or run the project locally.
2. Read each question carefully.
3. Answer before the timer runs out.
4. Complete the quiz and see your final score.

## Why This Project?
This project was created to combine learning, challenge, and fun in a single interactive web app. It demonstrates DOM manipulation, event handling, and game logic in a beginner-friendly way.

## Project Status
Active learning project focused on interactive web development.
